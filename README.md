# Tasty Jam Homebrew tap

Mac apps from [Tasty Jam App Development](https://tastyjam.ca).

```bash
brew install --cask nairdaleo/tastyjam/glimpse
```

| Cask | App |
| --- | --- |
| `glimpse` | [Glimpse](https://github.com/nairdaleo/Glimpse): compact menu-bar system monitor |

Casks are updated automatically when an app is released. Apps are signed with Developer ID and notarized by Apple.
